# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-03-16

### Added

- Org structure with seats, roles, and accountability chart
- AI agents with tool access and configurable runtime
- Academy module for onboarding and training content
- Performance review cycles with self and manager assessments
- Task management with assignments, priorities, and due dates
- Measurables tracking with goals and scorecards
- Incentive programs and compensation tracking
- Calendar with event scheduling and team visibility
- SOPs (Standard Operating Procedures) library
- Tools directory for managing org-wide resources
- Meetings module with agendas, notes, and action items
- Time-off requests and approval workflows
- Feedback system for continuous peer and manager input
- One-command deploy script (`deploy.sh`) for VPS setup

### Technical

- Hono API server with tRPC for type-safe client-server communication
- Drizzle ORM with PostgreSQL for database management
- Better Auth for authentication and session handling
- React SPA with Vite, Tailwind CSS, and shadcn/ui components
- Docker Compose deployment with PostgreSQL and app containers
- One-command `deploy.sh` for production VPS deployment
